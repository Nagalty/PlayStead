# PlayStead 0.3 Task 09 Tray Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add safe host startup ordering and a Windows tray lifecycle that keeps PlayStead/session monitoring alive when the main window is closed.

**Architecture:** Build the DI host before local database initialization but defer `IHost.StartAsync` until migrations and health checks succeed. Add a native WinForms `NotifyIcon`, a close-policy singleton, and session snapshot publication from `SessionMonitor`; normal window close hides, explicit tray Quit shuts down.

**Tech Stack:** C# 14 / .NET 10, WPF, Generic Host/DI, System.Windows.Forms NotifyIcon, xUnit, SQLite.

**Spec:** `docs/superpowers/specs/2026-09-13-playstead-0.3-task09-tray-lifecycle-design.md`
