# PlayStead 0.4.1 Media Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Steam-first, cache-first media pipeline that puts real game artwork into the running PlayStead Library, then exposes the same normalized media to Home without blocking startup or coupling UI code to Steam.

**Architecture:** Provider-neutral media contracts live in `PlayStead.Core`; deterministic user-data paths remain in `PlayStead.Platform`; file-backed media cache lives in `PlayStead.Data`; Steam local/CDN acquisition lives in `PlayStead.Providers`; resolver wiring and visual consumption live in `PlayStead.UI`. The UI receives only local file paths and normalized asset types. Each slice is closed only after automated GREEN plus runtime and visual acceptance.

**Tech Stack:** C# 14 / .NET 10, WPF, Microsoft Generic Host/DI, xUnit, `HttpClient`, existing PlayStead SQLite/local-first architecture, PowerShell 7 gates.

**Spec:** `docs/superpowers/specs/2026-09-14-playstead-0.4.1-media-foundation-design.md`

## Global Constraints

- Steam is the primary media source when a reliable Steam AppID is available.
- Resolution order for Steam is: PlayStead cache → Steam local cache → Steam CDN → PlayStead fallback.
- Network access MUST NOT block startup or initial Library rendering.
- Missing or failed media MUST leave a finished PlayStead fallback visible.
- UI code MUST NOT construct Steam CDN URLs or inspect Steam cache paths.
- IGDB remains architecturally possible but disabled in 0.4.1.
- No Twitch/IGDB client secret may be embedded anywhere in PlayStead.
- No title-only fuzzy matching is allowed for media.
- Media files are stored only under `%LOCALAPPDATA%\PlayStead\Media`.
- No third-party image or virtualization package is added.
- Existing Library row virtualization and Grid/List state restoration must remain intact.
- No eager download of the entire Library at application startup.
- Strict TDD RED → GREEN for every production behavior.
- No commit before the task-specific tests and independent gate are GREEN.
- A vertical slice is not CLOSED until `CODE_GREEN`, `TESTS_GREEN`, `RUNTIME_GREEN`, `VISUAL_GREEN`, and `PRODUCT_COHERENCE_GREEN` are all true.
- Final Release build must be 0 warnings / 0 errors.
- Current pre-0.4.1 full-suite baseline is 507 tests; never hard-code a new CI minimum until a fresh final count is observed.

```csharp
using PlayStead.Core.Library;

namespace PlayStead.Core.Media;

public sealed record GameMediaIdentity
{
    public GameMediaIdentity(
        ProviderKind provider,
        string providerGameId,
        string canonicalTitle,
        IReadOnlyDictionary<string, string>? externalIds = null)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(providerGameId);
        ArgumentException.ThrowIfNullOrWhiteSpace(canonicalTitle);

        if (provider == ProviderKind.Steam &&
            !providerGameId.All(char.IsAsciiDigit))
        {
            throw new ArgumentException(
                "Steam media identity requires a numeric AppID.",
                nameof(providerGameId));
        }

        Provider = provider;
        ProviderGameId = providerGameId.Trim();
        CanonicalTitle = canonicalTitle.Trim();
        ExternalIds = externalIds
            ?? new Dictionary<string, string>();
    }

    public ProviderKind Provider { get; }
    public string ProviderGameId { get; }
    public string CanonicalTitle { get; }
    public IReadOnlyDictionary<string, string> ExternalIds { get; }
}
```

- [ ] **Step 2: GREEN resolver orchestration**

Implement exactly:

```csharp
public string? TryGetCachedPath(
    GameMediaIdentity identity,
    GameMediaAssetType assetType) =>
    _cache.TryGetPath(identity, assetType);

public async Task<string?> ResolveAndCacheAsync(
    GameMediaIdentity identity,
    GameMediaAssetType assetType,
    CancellationToken cancellationToken)
{
    var cached = _cache.TryGetPath(identity, assetType);
    if (cached is not null)
    {
        return cached;
    }

    foreach (var provider in _providers)
    {
        cancellationToken.ThrowIfCancellationRequested();

        if (!provider.CanResolve(identity))
        {
            continue;
        }

        var payload = await provider.ResolveAsync(
            identity,
            assetType,
            cancellationToken);

        if (payload is null)
        {
            continue;
        }

        return await _cache.StoreAsync(
            identity,
            payload,
            cancellationToken);
    }

    return null;
}
```
