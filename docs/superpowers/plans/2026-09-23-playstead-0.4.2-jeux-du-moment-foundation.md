# Jeux du moment Foundation Implementation Plan

> **For agentic workers:** implement task-by-task with TDD and verify each step before continuing.

**Goal:** Add a persistent, bounded “Jeux du moment” shortlist and expose it from Game Detail only.

**Architecture:** Core owns the entry and service contract. Data owns an additive SQLite migration and transactional store/service implementation. UI injects the service into Game Detail and exposes membership-aware commands. Home remains untouched.

**Tech Stack:** .NET 10, C#, Microsoft.Data.Sqlite, CommunityToolkit.Mvvm, WPF.

**Spec:** `docs/superpowers/specs/2026-09-23-playstead-0.4.2-jeux-du-moment-foundation.md`

## Global Constraints
- Maximum five unique games; no automatic eviction.
- `GameId`, explicit position, and UTC `AddedAtUtc` only.
- Add and remove are idempotent; duplicate concurrent adds do not leak SQLite errors.
- No Home section, recommendation, backlog, schema-destructive migration, staging, commit, or push.

## Review Focus
- Migration from schema version 10: test additive application and reload in Data task.
- Concurrent duplicate add: test two service calls against one database and assert one entry.
- Invalid reorder input: test duplicates, unknown IDs, and incomplete lists are rejected without mutation.
- Game Detail command failure: test UI state remains unchanged when persistence fails.
- Existing Game Detail construction: run affected Game Detail regression tests.
