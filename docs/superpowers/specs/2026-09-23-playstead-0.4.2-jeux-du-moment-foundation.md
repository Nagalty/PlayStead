# Jeux du moment Foundation Specification

## Product intent
“Jeux du moment” is a small, manually managed shortlist of up to five games in the user’s current rotation.

## Non-goals
It is not a backlog, permanent favorites library, recommendation engine, automatic ranking, or Home section.

## Domain model
Each entry contains `GameId`, explicit zero-based `Position`, and UTC `AddedAtUtc`. Game IDs are unique.

## Service contract
`IGamesDuMomentService` exposes asynchronous `GetAsync`, `AddAsync`, `RemoveAsync`, and `ReorderAsync`. Add is idempotent; remove of a missing game is safe. A full list returns an explicit bounded result and never evicts another game. Reordering validates the complete ordered set and rejects duplicates, unknown IDs, or incomplete lists.

## Persistence contract
An additive SQLite migration creates a shortlist table with a unique `game_id`, explicit position, and UTC timestamp. Reads are ordered by position. Writes are transactional. Concurrent duplicate adds are treated as idempotent membership success even when the database unique constraint wins the race.

## Game Detail UX
Game Detail exposes one action whose copy is “Ajouter aux jeux du moment” or “Retirer des jeux du moment”. Membership is loaded and updates after successful commands. The command is unavailable while its operation is running and failures leave the prior state intact.

## Acceptance criteria
The service and store survive reload, enforce five entries, preserve deterministic order, compact removal, reject invalid reorders safely, and handle concurrent duplicate adds without an unhandled constraint error. Game Detail reflects membership and preserves existing behavior. Home is unchanged.
